# 构建与部署手册（x86_general 显示修复版）

## A. 从交付包部署（推荐，最快）

1. `tar xzf images/OpenHarmony-5.1.0-x86_general-images-20261020-displayfix.tar.gz`
2. `bash disk_assemble.sh /path/to/ohos_disk.img`（需 sgdisk/gdisk、grub-mkstandalone、dd）
3. 用 tools/launch_qemu.sh 启动（或 USAGE.md §3 的等价命令）
4. 按 USAGE.md §4「黄金启动公式」验证截图 ≥60,000 色

镜像内置可直接启动的成品盘：`images/ohos_disk_20261020.img`（免拼盘，已端到端验证）。

## B. 增量重编（改了补丁后回灌镜像）

前提：源码树 `/root/OpenHarmony/5.1-Release`，Ninja 用 `/root/oh_env/bin/ninja`（pip 版），**必须**带 `-w dupbuild=warn`。

```bash
cd /root/OpenHarmony/5.1-Release/out/x86_general

# EGL wrapper（platformsdk/libEGL.so）
/root/oh_env/bin/ninja -w dupbuild=warn graphic/graphic_2d/libEGL.so

# composer HAL（注意：运行时实际加载的是 system 分区 /vendor/lib64/ 下这份）
/root/oh_env/bin/ninja -w dupbuild=warn opc_soc_products/x86_general/libdisplay_composer_vendor.z.so

# 内核模块（三模块必须同一 make 调用；改 kernel/linux/linux-6.6 后先同步到 out/x86_general/kernel/src_tmp/linux-6.6 再编）
cd /root/OpenHarmony/5.1-Release/out/x86_general/kernel/src_tmp/linux-6.6
export PATH=/root/OpenHarmony/5.1-Release/prebuilts/clang/ohos/linux-x86_64/llvm/bin:$PATH
export DEVICE_NAME=x86_general PRODUCT_COMPANY=opc PRODUCT_PATH=vendor/opc/x86_general
make LLVM=1 LLVM_IAS=1 KBUILD_OUTPUT=/root/OpenHarmony/5.1-Release/out/x86_general/kernel/OBJ/linux-6.6 \
  drivers/virtio/virtio_dma_buf.ko drivers/gpu/drm/drm_shmem_helper.ko drivers/gpu/drm/virtio/virtio-gpu.ko -j$(nproc)
```

guest 内回灌（hdc 通了之后）：

```bash
hdc file send <产物> /data/local/tmp/ && hdc shell "mount -o remount,rw / && \
  cp /data/local/tmp/libEGL.so /system/lib64/platformsdk/libEGL.so && sync"
# virtio-gpu.ko → /system/lib/modules/virtio-gpu.ko（需重启 guest 生效）
# composer HAL → /system/vendor/lib64/libdisplay_composer_vendor.z.so（注意是 system 分区的 /vendor 目录）
```

**回灌任何图形组件后必须 QEMU 冷启动**（热环境会触发 wrapper 崩溃环，见根因分析）。

## C. 全量源码构建（仅重建整套基线时）

参考 vendor_opc 流程：`./build.sh --product-name x86_general --ccache`（Ubuntu 24.04 需 Python3.10 venv + glibc 兼容补丁，细节见源码树 build/config 与历史经验）。全量构建产物不含本包的 mesa/wrapper/内核热修——**除非把 §B 的补丁都编进去再拼盘**；日常迭代用 §B 增量 + disk_assemble.sh。

## D. 相关 marker 开关（都在 guest /data）

| marker | 作用 | 默认 |
|--------|------|------|
| `/data/egl_no_init` | 存在=eglInitialize 强制失败→全系统 CPU 渲染（**截图非黑的关键**） | **有（勿删）** |
| `/data/hdi_mirror` | 存在=composer 把 client buffer 镜像到 /dev/fb1 并跳过 plane commit（硬件屏旁路实验） | 无 |
